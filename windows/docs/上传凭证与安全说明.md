# 上传凭证与安全说明

## 一、两个"钥匙"的分工

| 凭证 | 用在哪 | 能做什么 | 不能做什么 |
|---|---|---|---|
| **上传凭证 (token)** | 手机 MacroDroid 脚本里 | 向 `打卡/` 前缀**新增** ≤10MB 的图片 | 覆盖已有文件、删除、列举、读取桶内其他前缀 |
| **AK/SK** | 仅电脑端 config.json | 完整管理：列举/下载/删除/上传 | （请勿放手机） |

token 由 `token_gen.py` 用 SK 签名生成，手机端**不需要也无法**接触 SK。

## 二、token 的权限边界

policy 内容（可用 `token_gen.py` 生成后反解核对）：

```json
{
  "scope": "<桶名>:打卡/",     // 只允许该前缀
  "isPrefixalScope": 1,        // 前缀限定模式（必加）
  "deadline": <now+10年>,
  "insertOnly": 1,             // 只新增，禁止覆盖
  "fsizeLimit": 10485760,      // 单文件 ≤10MB
  "mimeLimit": "image/*"       // 只允许图片
}
```

即便 token 完全泄露，攻击者也只能往 `打卡/` 前缀塞不超过 10MB 的图片，
不能读取/删除/覆盖你的打卡截图，更碰不到桶里其他东西。

## 三、泄露了怎么办

1. 七牛控制台删除 `打卡/` 前缀下的可疑对象；
2. 电脑上重新跑 `token_gen.py` 生成新 token（新 token 与旧 token 同时有效，
   但 insertOnly 保证旧 token 无法覆盖新上传的文件）；
3. 更新手机宏脚本里的 `TOKEN`。

> 若想彻底作废旧 token：七牛密钥对不支持单独吊销上传凭证，
> 只能通过更换密钥对（控制台 → 密钥管理）实现，代价是 AK/SK 也要同步更新。

## 四、电脑端 SK 的存储风险

- SK 以**明文**保存在 `%APPDATA%\qiniu-clockin-sync\config.json`。
- 建议：不要在公用电脑配置；如需更安全，可在七牛控制台为本项目
  单独创建一对密钥，并定期轮换（换钥匙后记得在设置页同步修改并重新生成手机 token）。
- 后续版本如需要可增加 Windows DPAPI 加密存储。

## 五、日常自检

- 手机上传后 60 秒内没成功通知 → 看本文档"泄露了怎么办"之前的
  《MacroDroid配置步骤.md》常见问题。
- 电脑端"测试连接"报错 → 检查 AK/SK、桶名、区域；域名报错优先检查
  桶是否绑定了有效域名（七牛免费测试域名 30 天后回收，见《Windows使用说明.md》）。
