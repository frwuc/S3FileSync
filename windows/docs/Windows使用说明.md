# Windows 电脑端使用说明（S3FileSync）

## 一、安装（一次性）

项目目录：`E:\agentwork\qiniu-clockin-sync`，Python：`D:\02soft\python312`（已装好依赖）。

如需在新机器安装：
```
D:\02soft\python312\python.exe -m pip config set global.index-url https://mirrors.aliyun.com/pypi/simple/
D:\02soft\python312\python.exe -m pip install -r requirements.txt
```

## 二、启动

| 方式 | 操作 |
|---|---|
| 带窗口启动（调试推荐） | 双击 `run.pyw` |
| 无窗口常驻 | 运行 `start_silent.vbs` |
| 开机自启 | 设置页勾选「开机自动启动」（写入 HKCU Run，启动项名 `S3FileSync`） |

关闭主窗口只是**隐藏到托盘**，程序继续按间隔自动同步；退出请用托盘图标右键 → 退出。

## 三、配置（设置页）

必填：AK / SK / 空间名 / 存储区域 / 本地目录。
选填：下载域名（留空自动用桶绑定域名）、云端目录（Key 前缀，**留空 = 整个空间**）、
同步间隔（默认 30 分钟）、网络代理。

- **同步方向**：仅下载（云端→本地）/ 仅上传（本地→云端）/ 双向同步。
- **本地目录**：既是下载目标，也是上传来源；旁边「浏览…」选择、「打开目录」直接在资源管理器打开。
- **云端目录**：旁边「浏览远端」跳到文件浏览页按该前缀列举、「打开云端」在浏览器打开七牛控制台。
- **上传覆盖同名**：默认关闭。同名但内容不同时跳过并记录警告；开启后以本地文件覆盖云端。

流程建议：
1. 填写并保存；
2. 点 **测试连接**：验证 AK/SK/空间/区域、解析桶域名，并探测一次私有下载 URL；
3. 点 **测试上传**：上传一个极小的临时对象并立即删除，确认上传链路可用；
4. 点 **立即同步** 验证同步方向。

## 四、日常使用

- **自动同步**：按间隔执行当前方向。本地目录与云端 Key 一一对应，例如
  云端 `rtkq-data/报告.pdf` ⇄ 本地 `D:\03data\qiniudata\rtkq-data\报告.pdf`。
  已同步的（按 etag 记录在 `sync_state.json`）自动跳过；上传同样按 etag 比对，不会重复传。
- **临时单跑**：顶部「单跑 ▾」或托盘菜单，可只上传一轮 / 只下载一轮 / 双向一轮，不改默认设置。
- **文件浏览页**：
  - 「云端目录」可填任意前缀，与设置页的同步范围无关；留空浏览整个空间；
    「全部文件」回根目录、「上级」回上一层，双击以 `/` 结尾的目录占位对象可进入目录；
  - 「上传文件…」「上传文件夹…」上传到当前云端目录（保留子目录结构，同名覆盖）；
  - 多选**下载选中**或**删除选中**（删除有确认，不可恢复）、双击下载、点表头排序、右键复制 Key；
  - 「打开云端」在浏览器打开七牛控制台当前空间。
- **托盘菜单**：打开主窗口 / 立即同步 / 仅上传一轮 / 仅下载一轮 / 暂停自动同步 /
  打开本地目录 / 打开云端目录 / 退出。
- **日志**：设置、同步、上传、下载、删除等全部记录；文件日志在
  `%APPDATA%\qiniu-clockin-sync\app.log`（1MB 自动轮转 ×2）。

## 五、重要：下载域名与七牛测试域名

- 下载走桶的**绑定域名** + 私有签名 URL；上传走区域上传端点（`up-<region>.qiniup.com`），与下载域名无关。
- **七牛的免费测试域名只有 30 天有效期**，回收后下载会失败。
  长期使用请给桶绑定自己的域名，并在设置页更新"下载域名"。
- 配置目录沿用旧名 `qiniu-clockin-sync`，保证升级后 AK/SK 与已同步状态不丢失。

## 六、故障排查

| 现象 | 处理 |
|---|---|
| 测试连接报"获取桶域名失败/未绑定域名" | 桶没有可用域名：控制台绑定域名后填入设置页 |
| 列举/下载/上传报代理错误 | 设置页「网络代理」改为「直连」；默认 auto 会自动忽略失效代理 |
| 上传 0 条 | 检查本地目录是否正确、云端目录前缀是否匹配；同名同内容文件按设计跳过 |
| 上传被跳过且日志提示"内容不同" | 默认不覆盖云端，需要覆盖请在设置页勾选「上传时覆盖云端同名文件」 |
| 下载报 403 | 域名已失效（如测试域名过期）→ 换域名 |
| 中文文件夹乱码 | 本程序直接按 Unicode 文件名落盘，资源管理器正常显示 |
| 想强制全部重新下载 | 删除 `%APPDATA%\qiniu-clockin-sync\sync_state.json` 后"立即同步"（本地同名同大小文件会自动识别跳过重下） |
| 程序没起来 | 看 `%APPDATA%\qiniu-clockin-sync\app.log`；用 `run.pyw` 方式启动看报错 |
