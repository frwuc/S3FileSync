# S3FileSync

S3 兼容对象存储同步工具（当前后端：**七牛云 Kodo**，其他 S3 兼容服务商尚未验证）：
把**任意文件**在本地目录与云端空间之间同步，支持三种方向。

| 方向 | 含义 |
| --- | --- |
| 仅下载 | 云端 → 本地（旧版默认行为） |
| 仅上传 | 本地 → 云端 |
| 双向同步 | 先上传本地新增，再下载云端新增 |

本地根目录与对象 Key 一一对应，例如：

```
云端  rtkq-data/报告.pdf   ⇄   本地  D:\03data\qiniudata\rtkq-data\报告.pdf
云端  照片/2026/a.jpg      ⇄   本地  D:\03data\qiniudata\照片\2026\a.jpg
```

上传时用七牛 etag 与云端同名对象比对，内容一致直接跳过，不会重复传输；
同名但内容不同默认**跳过不覆盖**，可在设置页打开「上传时覆盖云端同名文件」。

## 主要功能

- **自动同步**：按间隔（默认 30 分钟）按设定方向跑一轮，托盘常驻、可开机自启。
- **临时单跑**：顶部「单跑 ▾」或托盘菜单，可只上传一轮 / 只下载一轮 / 双向一轮，不改默认设置。
- **任意云端目录**：文件浏览页的「云端目录」输入框可填任意 Key 前缀，留空即浏览整个空间；
  「全部文件」一键回到根目录，「上级」回到上一层，双击以 `/` 结尾的目录占位对象可进入该目录。
- **手动上传**：文件浏览页「上传文件…」「上传文件夹…」，上传到当前云端目录，保留子目录结构，同名覆盖。
- **手动下载 / 删除**：多选、双击下载、点表头排序、右键复制 Key、分页。
- **目录快捷打开**：设置页本地目录旁「浏览… / 打开目录」，云端目录旁「浏览远端 / 打开云端」
  （浏览器打开七牛控制台）；文件浏览页也有「打开云端」。
- **网络容错**：自动探测直连，直连可用时忽略失效的系统代理；也可手动选「直连 / 系统代理」。
- **自检**：「测试连接」列举 + 私有下载探测；「测试上传」上传一个极小临时对象后立即删除，验证上传链路。

## 快速开始

```
双击 run.pyw（或 start_silent.vbs 无窗口启动）
→ 设置页填 AK / SK / 空间名 / 存储区域 / 本地目录
→ 选同步方向、云端目录（可留空）
→ 测试连接 / 测试上传 → 保存设置 → 立即同步
```

CLI 调试：

```
D:\02soft\python312\python.exe -m app.sync --once                 # 按配置方向
D:\02soft\python312\python.exe -m app.sync --once --mode upload   # 仅上传一轮
D:\02soft\python312\python.exe -m app.sync --once --mode both     # 双向一轮
```

配置与状态仍在 `%APPDATA%\qiniu-clockin-sync\`（`config.json` / `sync_state.json` / `app.log`）。
目录名沿用旧版，保证升级后 AK/SK 与已同步状态不丢失；软件显示名称已改为「S3FileSync」。

## 目录结构

```
run.pyw                 GUI 启动入口
start_silent.vbs        无窗口启动
app/                    程序（GUI / 同步引擎 / 七牛封装）
token_gen.py            可选：手机端长期上传凭证生成 + 全链路自检
docs/                   配置与使用文档
requirements.txt        依赖（qiniu / requests / pystray / Pillow）
```

## 手机端（可选的历史用法）

`docs/MacroDroid配置步骤.md` 里的打卡截图自动上传方案仍可用：手机不接触 AK/SK，
用 `token_gen.py` 生成的受限凭证直传 `打卡/` 前缀；电脑端把云端目录设为 `打卡/`、方向选「仅下载」即可。
这不是必须项，本程序现在也可以纯粹当作电脑 ↔ 七牛的通用文件同步工具。

## 安全要点

- SK 明文保存在本机 `config.json`，勿用于公用电脑；
- 手机端受限 token 只允许指定前缀新增，泄露影响有界；
- 详见 `docs/上传凭证与安全说明.md`。

## 注意

- 七牛免费测试域名 30 天回收，长期使用请给桶绑定自定义域名；
- 中文对象 Key 的私有下载 URL 已做 UTF-8 编码处理，上传也无需手工转码；
- 云端「目录」本质是 Key 前缀，不是真实文件夹；删除对象不可恢复。
